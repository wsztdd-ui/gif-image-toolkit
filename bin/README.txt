本目录放入 ffmpeg.exe 与 ffprobe.exe（Windows x64 版），随软件一起打包成绿色便携版。

下载地址（任选其一）：
- gyan.dev 完整版: https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
- BtbN 自动构建:   https://github.com/BtbN/FFmpeg-Builds/releases （ffmpeg-master-latest-win64-gpl.zip）

解压后把 bin\ 下的 ffmpeg.exe、ffprobe.exe 复制到这里即可。
未放入时，程序会尝试使用系统 PATH 中的 ffmpeg。
