# 需求文档（GifKit）

版本：v0.2（按 2026-10-03 第一轮反馈修订）　日期：2026-10-03　状态：待最终确认

> v0.2 修订记录：新增动图 GIF 再压缩（FR1-11）、输出预览（FR1-12）；默认输出改为 720×405；帧率改为自由输入（最小 3）；图片页明确格式转换能力。

## 1. 背景与目标

- 日常素材以 **TS 视频流**为主（电视台/制作场景），需要经常从中截取片段做成 GIF（微信/QQ 可直接发送的体积）。
- 同时需要一款顺手的**批量图片压缩**工具。
- 目标产物：**Windows 绿色便携版 exe**——免安装、免配置、拷到任意目录/U盘可用、离线工作、不上传任何数据。

## 2. 功能需求

### FR1 视频转 GIF（主功能）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR1-1 | 文件导入 | 支持拖拽到窗口、按钮选择。格式：`.ts` `.m2ts` `.mts` `.mp4` `.m4v` `.mkv` `.avi` `.mov` `.flv` `.webm` `.wmv` `.mpg` `.mpeg` `.3gp`（以 TS 为一等公民） |
| FR1-2 | 媒体信息 | 导入后自动显示：分辨率、时长、帧率、编码格式、文件大小 |
| FR1-3 | 时间选取 | 起点（秒，可精确到 0.1s）+ 时长；滑杆粗调 + 数值精调；缩略图条点选起点；"选整段"快捷键 |
| FR1-4 | 裁剪范围 | 在预览帧上**鼠标拖拽框选**；可拖动、可四角缩放；比例锁定：自由 / 16:9 / 1:1 / 9:16 / 4:3；一键重置为全画面；显示选区像素坐标与尺寸 |
| FR1-5 | 输出参数 | 宽度（分辨率）：**默认 720**（16:9 源即 720×405）/ 原始 / 640 / 480 / 360 / 240 / 自定义；帧率：**自由输入，最小 3**（上限 30，默认 12）；颜色数：256/128/64/32；抖动：Bayer（体积小）/ Floyd（更平滑）/ 无 |
| FR1-6 | 质量预设 | 高质量 / 均衡（默认）/ 高压缩 三档，一键联动帧率、颜色数、抖动；手动改动任意单项后视为"自定义" |
| FR1-7 | 体积预估 | 根据当前参数实时给出粗略输出体积；明确标注为估算 |
| FR1-8 | 生成与反馈 | 进度条（按已处理时长计算百分比）；可取消；完成后显示产物大小与耗时；一键打开输出目录 |
| FR1-9 | 输出规则 | 输出目录：与源文件同目录（默认）/ 自定义；文件名：`源文件名 + 后缀(.gif)`，默认后缀 `_gif`；自动防覆盖 |
| FR1-10 | GIF 质量 | 采用两遍调色板法（palettegen/paletteuse），Lanczos 缩放，色彩明显优于单遍转换 |
| FR1-11 | 动图 GIF 再压缩 | 拖入 `.gif`（动图）自动识别并进入再压缩流程：沿用同一管线重编码（重设调色板），可再调宽度、帧率（抽帧降帧）、颜色数、抖动、时间范围与裁剪；显示原始帧数/时长/体积与压缩前后对比 |
| FR1-12 | 输出预览 | 生成前先**预览**：按当前参数在临时目录生成 GIF 并在界面内嵌播放，显示实际体积与尺寸；确认后点"保存"写入输出目录，不满意可直接调整参数重新预览，避免反复写盘试错。预览产物与最终保存产物完全一致 |

### FR2 图片压缩

| 编号 | 需求 | 说明 |
|---|---|---|
| FR2-1 | 文件导入 | 拖拽/按钮批量添加：`.jpg` `.jpeg` `.png` `.webp` `.bmp` `.gif`(静态) `.tif` `.tiff` |
| FR2-2 | 输出格式（含格式转换） | 保持原格式（默认）/ JPEG / WebP / PNG，选输出格式即**格式互转**（如 PNG→JPG、JPG→WebP、BMP→PNG）；BMP/TIFF 在"保持"模式下转 PNG（更小）；支持 jpg/png/webp/bmp/gif(静态)/tiff 之间不限方向互转 |
| FR2-3 | 质量参数 | 质量滑杆 1–100（默认 80，仅对 JPEG/WebP 生效） |
| FR2-4 | 尺寸限制 | 最长边限制：原始 / 2560 / 1920 / 1280 / 800 / 自定义，只缩不放，Lanczos 高质量缩放 |
| FR2-5 | PNG 量化 | 可选 256 色量化（对截图、UI 图效果显著），默认开启 |
| FR2-6 | 批量与对比 | 列表逐行显示：原大小 → 压缩后大小 → 节省百分比；汇总总节省量；自动跳过"压缩后反而变大"的文件 |
| FR2-7 | 输出规则 | 与 FR1-9 相同，默认后缀 `_c`；完成后一键打开输出目录 |

### FR3 通用

| 编号 | 需求 | 说明 |
|---|---|---|
| FR3-1 | 绿色便携 | 免安装；单 exe（或单文件夹）即全部；运行不写注册表；设置保存在程序目录 `config.json`（目录只读时自动回退到用户目录） |
| FR3-2 | 自带解码器 | 随包内置 ffmpeg/ffprobe，不依赖目标机器安装任何东西 |
| FR3-3 | 中文界面 | 全中文 UI，界面即时响应（耗时操作全部后台线程，不卡界面） |
| FR3-4 | 健壮性 | 损坏/不支持的文件给出中文错误提示，不崩溃 |

## 3. 非功能需求

- 支持系统：Windows 10 / 11（64 位）。
- 离线可用，无任何联网行为。
- 大文件友好：TS 素材常见几百 MB～几 GB，取信息、取帧必须秒级响应（快速定位，不做全文件扫描）。
- 安装包/程序体积：单文件版 ≤ 80MB 量级（含 ffmpeg）。

## 4. 本版本明确不做（可进后续版本）

- 录屏、摄像头采集
- 字幕烧录、文字/图片水印
- 输出 APNG / 动图 WebP
- 批量视频转 GIF 队列
- 多语言

## 5. 验收标准

1. 拖入一个 1GB 的 TS 文件，3 秒内显示媒体信息并出现缩略图条。
2. 框选裁剪 + 默认参数（720 宽 / 12fps / 128 色 / Bayer），截取 5 秒：先"生成预览"内嵌播放确认体积，再保存，GIF 可在微信中发送且画面清晰无明显色带；16:9 源输出恰为 720×405。
3. 拖入一个动图 GIF，调小宽度与帧率后预览，保存后体积明显小于原文件且画面流畅。
4. 图片页批量拖入 50 张截图，选择转 WebP 一键压缩，列表能看到每张的节省比例。
5. 帧率输入框无法输入小于 3 的值。
6. 整个软件复制到另一台 Win10 电脑（无 Python、无 ffmpeg）双击可用。
7. 全程断网，功能不受影响。
