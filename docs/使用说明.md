# 使用说明（GifKit 绿色便携版）

免安装：把 `GifKit.exe`（或 `GifKit` 文件夹）拷到任意位置，双击即用。全程本地处理，不上传任何数据。

## 一、视频截取 GIF

1. 把视频**拖进窗口**（支持 TS / M2TS / MP4 / MKV / AVI / MOV / FLV / WebM / WMV 等；**动图 GIF 拖进来则进入再压缩**），或点左上角“选择视频”。
2. **选时间段**：直接**拖动时间条两端的滑块**（左=起点、右=结束，拖中间可整体平移），也可用下方的起点/时长数字框精确输入，或点缩略图设起点；要整段就点”选整段”。
3. **播放选段**：点时间条上方的 **”▶ 播放选段”**，上方画面按当前裁剪/宽度/帧率循环播放效果；播放中按钮变”⏹ 停止预览”，点击画面也可停止并回到编辑。改参数时正在播放会自动按新参数重新播放。
4. **框选画面范围**：在预览图上拖一个框（拖动时间后画面停在起点帧，方便框选）；框内拖动可移动、四角可缩放；右侧可锁定比例（16:9 / 1:1 / 9:16 / 4:3）；”重置”恢复全画面。
5. **调输出参数**（右侧“输出设置”）：
   - 宽度：默认 720（16:9 画面正好 720×405，适合微信/QQ 发送）
   - 帧率：自由输入，最小 3；帧率越低体积越小
   - 颜色数与抖动：截图类内容用“无抖动”更干净，渐变多的画面用 Floyd 更平滑
   - 懒人方式：直接选“高质量 / 均衡 / 高压缩”三档预设
6. **生成 GIF**：点右下角“生成 GIF”，完成后界面里直接循环播放**实际产物**并显示真实体积；确认后点“保存到输出目录”，默认保存在源视频同目录、文件名加 `_gif` 后缀，可在“输出位置”改为自定义目录，完成后可一键打开所在目录。

小技巧：体积主要取决于 **画面尺寸 × 时长 × 帧率**。想再小一档：宽度 720→480、帧率 12→8、颜色 128→64，体积大约降一半以上。

## 二、图片压缩 / 格式转换

1. 把图片**批量拖进“图片压缩”页**（JPG / PNG / WebP / BMP / 静态 GIF / TIFF）。
2. 右侧设置：输出格式（保持原格式 = 只压缩；选 JPEG/WebP/PNG = 顺便转换格式）、质量滑杆、最长边限制（比如发朋友圈选 1920）、PNG 256 色量化。
3. 点“开始压缩”，列表里逐行显示**原大小 → 压缩后 → 节省百分比**；压缩后反而变大的文件会自动跳过不动它。
4. “打开输出目录”查看产物（默认源目录、文件名加 `_c` 后缀，不会覆盖原图）。

## 三、常见问题

| 现象 | 说明 |
|---|---|
| 提示“未找到 ffmpeg” | 便携包应自带 `bin\ffmpeg.exe`；若自己构建的版本漏了它，按 `bin\README.txt` 补齐 |
| TS 文件时长显示“未知” | 个别 TS 流没有时长元数据：直接手动输入起点/时长即可，其余功能不受影响 |
| GIF 体积比预估大很多 | 预估只是粗略参考；以“生成预览”显示的实际体积为准 |
| 设置会不会乱写系统 | 只在程序目录写一个 `config.json`（目录只读时才写用户目录），卸载即删、无残留 |
