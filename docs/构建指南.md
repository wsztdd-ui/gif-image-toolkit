# 构建指南（GifKit）

面向开发者/维护者。最终产物：Windows 绿色便携版。

## 1. 环境准备

1. 安装 Python 3.10+（勾选 *Add python.exe to PATH*），验证：
   ```
   python --version
   ```
2. 获取 ffmpeg / ffprobe（Windows x64）：
   - 推荐 [gyan.dev essentials](https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip) 或 [BtbN builds](https://github.com/BtbN/FFmpeg-Builds/releases)（ffmpeg-master-latest-win64-gpl.zip）
   - 解压后把 `bin\ffmpeg.exe`、`bin\ffprobe.exe` 复制到项目 `bin\` 目录
   - 不放入时开发调试会回退用 PATH 中的 ffmpeg；**打包便携版必须放入**，否则产物在别的机器不可用

## 2. 开发运行

```
cd /d D:\gif截取压缩
python -m pip install -r requirements.txt
run.bat        （即 python src\main.py）
```

无界面回归测试（不启动 GUI，验证 ffmpeg 管线与图片压缩）：

```
python tests\test_pipeline.py
```

## 3. 打包绿色便携版

```
build\build.bat          → 单文件版  dist\GifKit.exe（约 60–80MB，内含 ffmpeg）
build\build.bat onedir   → 文件夹版  dist\GifKit\
```

- 单文件版：拷走一个 exe 即用；首次启动需自解压，慢 1–3 秒。
- 文件夹版：启动快；把整个 `dist\GifKit\` 文件夹压缩为 zip 即绿色便携包。
- 打包产物运行期只在程序目录写 `config.json`（目录只读时回退 `%APPDATA%\GifKit`），不写注册表。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 杀毒软件报 PyInstaller 单文件 exe | 提供文件夹版；或对 exe 做代码签名后分发 |
| 用户机器上已有旧版 ffmpeg | 无影响，程序优先使用自带 `bin\` 内的版本 |
| PySide6 装不上（网络） | `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple PySide6 Pillow` |
| 中文路径打包报错 | PyInstaller 支持中文路径；如遇问题可把项目移到纯英文路径重试 |
